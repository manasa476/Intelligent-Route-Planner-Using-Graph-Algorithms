# Intelligent Route Planner Using Graph Algorithms

## Overview

A Java-based route planning system that finds the shortest route between locations using Dijkstra's Algorithm.

## Features

- Graph Representation using Adjacency List
- BFS Traversal
- DFS Traversal
- Dijkstra Shortest Path Algorithm
- Route Summary Generation
- Menu Driven Interface

## Technologies Used

- Java
- HashMap
- Queue
- Priority Queue
- Graph Data Structure

## How to Run

javac \*.java

java Main
